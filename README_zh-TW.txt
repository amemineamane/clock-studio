============================================================
  換裝時鐘 Clock Studio - OBS 直播用時鐘素材
============================================================

可以放在 OBS 直播畫面上的「換裝時鐘」。
在設定畫面就能輕鬆切換 100 種設計，
顏色、字型、要顯示的項目也都能依喜好調整。
背景是透明的，可以直接疊在遊戲畫面或聊天畫面上。

※ 免費版只有 8 種設計 (基本 / 膠囊 / 霓虹 / 七段顯示 / 新聞 / 粉彩 /
  和風 / 指針)。
  顏色、字型、外框、動畫為固定。
  付費版可以使用全部 100 種設計，也能更改顏色、字型等。


■ 簡單使用方法

【A】直接使用 (最簡單)

  1. 在 OBS 的「來源」按「+」→ 選擇「瀏覽器」新增
  2. 勾選「本機檔案」，
     按「瀏覽」選擇這個資料夾裡的 clock.html
  3. 設定寬度、高度後按確定 (參考：寬度 350 / 高度 130)

  會用預設的「基本」設計顯示目前時間。

【B】依喜好換裝

  1. 在這個資料夾裡的 settings.html 上按兩下開啟
     (會用瀏覽器開啟設定畫面)
  2. 設定畫面全部集中在同一個畫面。一邊看中間的預覽，
     一邊依照 左 → 右 → 中間下方 的順序操作。
       ① 選擇設計 (左)
            … 點卡片即可選定。滑鼠移到卡片上，可以在預覽中試看。
              也可以依名稱或風格搜尋、用「大圖瀏覽」放大查看一覽，
              或用預覽的 ◀ ▶ 依序切換。
              (也可以加入我的最愛，或使用「隨機」)
       ② 調整 (右)
            … 秒數・日期・12 小時制的開關、附加文字、顏色、字型、大小。
              顏色從「推薦配色」挑選最簡單。
              外框・陰影・動畫・位置・時區在「進階設定」裡。
       ③ 放進 OBS (中間下方)
            … 這裡有「複製網址」按鈕，以及要填入 OBS 的寬度・高度。
  3. 按下 ③ 的「複製網址」
     (第一次複製時，會自動開啟放進 OBS 的說明)
  4. 在 OBS 新增瀏覽器來源 (或開啟已有的來源)，
     【取消勾選】「本機檔案」，先刪除網址欄位原有的文字，再貼上剛才複製的網址（Ctrl + V / ⌘ + V）
  5. 在寬度・高度填入 ③ 的「寬度 × 高度」數字後按確定
     (點數字就能複製。開關秒數或日期、
      改變大小時，數字也會跟著變)

  設定會自動儲存，下次開啟時可以接著繼續。
  切換設計時，顏色和字型會恢復成該設計的預設。

  之後想更改設定時，把 OBS 的網址貼到 ③ 的「從 OBS 的網址讀取」，
  就能接著修改。改好後，請重新複製網址並貼到 OBS。


【C】切換語言 (日文 / English / 繁體中文)

  ・設定畫面的語言，可以用右上角的「語言」切換。
    第一次開啟時，會依瀏覽器的語言顯示。
  ・時鐘上顯示的文字 (日期的星期、上午/下午、「對話框」設計的文字等)，
    可以在 ② 的「時鐘語言」選擇。預設與設定畫面的語言相同。
  ・使用國字數字的設計 (和風、短冊、金箔、毛筆)，在任何語言下都維持國字數字。

■ 可以設定的項目

  ・設計              100 種可選 (免費版 8 種)
  ・日期位置          時鐘的 上 / 下 / 左 / 右
  ・12 / 24 小時制    12 小時制可以選擇 AM/PM 或 上午/下午
  ・秒數顯示          開 / 關
  ・冒號閃爍          開 / 關
  ・小時補 0          09:05 / 9:05
  ・日期顯示與格式    10月3日(六) / 2026年10月3日(六) / 民國115年10月3日(六) /
                      2026/10/03 Sat / 2026.10.03 SAT / Sat, Oct 3
  ・語言              設定畫面的語言 (日文 / English / 繁體中文)。在右上角切換
  ・時鐘語言          日期的星期、上午/下午、「對話框」的文字等所用的語言 (日文 / English / 繁體中文)
  ・附加文字          在時鐘下方顯示喜歡的文字 (例：JST、直播中)
  ・字型              19 種 (付費版)
  ・顏色              每個設計的推薦配色，或自由設定最多 3 處 (付費版)
  ・大小              30% ～ 400%
  ・文字外框          粗細和顏色 (付費版)
  ・陰影              加上陰影
  ・數字切換動畫      淡入 / 滑動 / 彈跳 (付費版)
  ・畫面中的位置      水平 (左・中・右) / 垂直 (上・中・下)
  ・時區              留空為電腦的時間，指定後也能顯示其他地區的時間

  ※ 和風、短冊、金箔、毛筆的日期，以及短冊的時間，
    在任何語言下都使用國字數字 (十月三日 等)。


■ 顯示不正常時

  Q. 改了設定，OBS 的顯示卻沒變
  A. 如果瀏覽器來源的「本機檔案」還是勾選狀態，
     設定就不會套用。請取消勾選，在網址欄位
     貼上用 settings.html 產生的網址。

  Q. 文字被切掉 / 超出範圍
  A. 瀏覽器來源的寬度・高度太小了。
     請填入 settings.html 的 ③ 顯示的「寬度 × 高度」數字。
     加上秒數・日期・附加文字，或把大小調大時，
     建議值也會改變，重新產生網址時請再確認一次。

  Q. 字型和設定的不一樣
  A. 字型是從網路載入的。
     沒有連網時，會用電腦裡的替代字型顯示。
     OBS 不用關閉，確認網路連線後，
     按瀏覽器來源的「更新當前頁面快取」試試看。

  Q. 在明亮的畫面上，白色文字不好閱讀
  A. 在「進階設定」加上「文字外框」(付費版)，
     設成深色就會比較清楚。
     免費版推薦文字後面有底板的「膠囊」「粉彩」「七段顯示」「新聞」
     「和風」，或有錶盤的「指針」。

  Q. 移動資料夾後就不顯示了
  A. 網址裡包含檔案的位置。
     移動資料夾或改名時，請重新開啟 settings.html
     產生新網址，再重新貼到 OBS。


■ 檔案內容

  clock.html      要加入 OBS 瀏覽器來源的時鐘本體
  clock-data.js   設計和字型的定義 (請勿刪除或移動)
  settings.html   設定畫面 (在這裡調整並產生網址)
  thumbs          設定畫面一覽用的圖片，請勿刪除
  i18n            語言資料 (日文 / 英文 / 繁體中文)，請勿刪除
  README_zh-TW.txt  這份說明 (另附日文版 README.txt 和英文版 README_en.txt)

  ※ 這些檔案和資料夾請放在同一個資料夾裡，不要分開。


■ 系統需求

  - 建議使用 OBS Studio 30 以上
  - Windows / macOS 皆可使用
  - 設定畫面請用 Chrome / Edge 等瀏覽器開啟
  - 載入字型需要網路連線
    (沒有連網時，時鐘仍會用替代字型正常運作)
