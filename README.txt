============================================================
  きせかえ時計 Clock Studio - OBS 配信用の時計素材
============================================================

OBS の配信画面に表示できる「きせかえ時計」です。
デザイン 100 種類を設定画面でかんたんに切り替えて、
色やフォント、表示する項目まで好みに合わせて変更できます。
背景は透明なので、ゲーム画面や雑談画面の上にそのまま重ねられます。

※ 無料版は 8 デザイン (プレーン / ピル / ネオン / 7セグ / ニュース / パステル /
  和風 / アナログ) のみ。
  色・フォント・フチ・時刻の変わり方は固定です。
  有料版は 100 デザインすべてと、色・フォントなどの変更が使えます。


■ かんたんな使い方

【A】そのまま使う (いちばん簡単)

  1. OBS のソースの「+」→「ブラウザ」を選んで追加
  2. 「ローカルファイル」にチェックを入れ、
     「参照」からこのフォルダの clock.html を選ぶ
  3. 幅・高さを設定して OK (目安: 幅 350 / 高さ 130)

  標準の「プレーン」デザインで、いまの時刻が表示されます。

【B】好みにきせかえる

  1. このフォルダの settings.html をダブルクリックして開く
     (ブラウザで設定画面が開きます)
  2. 設定画面は 1 つの画面にまとまっています。まん中のプレビューを見ながら、
     左 → 右 → まん中の下 の順に触ってください。
       ① デザインを選ぶ (左)
            … カードをクリックで決定。マウスを乗せると、プレビューで試し表示できます。
              名前やジャンルで探したり、「大きく並べて選ぶ」で一覧を大きく見たり、
              プレビューの ◀ ▶ で順番に切り替えたりもできます。
              (お気に入り登録や「おまかせ」も使えます)
       ② 好みに調整 (右)
            … 秒・日付・12 時間表示のオン/オフ、ひとこと、色、フォント、大きさ。
              色は「おすすめ配色」から選ぶのがかんたんです。
              フチ・影・時刻の変わり方・位置・タイムゾーンは「くわしい設定」の中にあります。
       ③ OBS に入れる (まん中の下)
            … 「URL をコピー」ボタンと、OBS に入れる幅・高さが出ています。
  3. ③ の「URL をコピー」を押す
     (はじめてコピーしたときは、OBS への入れ方の説明が自動で開きます)
  4. OBS でブラウザソースを追加 (または既存のものを開く) し、
     「ローカルファイル」のチェックを【外して】、URL 欄に最初から入っている文字を
     消してから、コピーした URL を貼り付け (Ctrl + V / Mac は ⌘ + V)
  5. 幅・高さに、③ の「幅 × 高さ」の数字を入力して OK
     (数字をクリックするとコピーできます。秒や日付をオン/オフしたり
      大きさを変えたりすると、数字も変わります)

  設定は自動で保存され、次に開いたときも続きから始まります。
  デザインを変えると、色とフォントはそのデザインの標準に戻ります。

  あとで設定を変えたくなったら、③ の「OBS の URL から読み込む」に OBS の URL を
  貼れば、続きから直せます。設定を変えたときは、URL をコピーし直して OBS に貼り直します。


【C】言語の切り替え (日本語 / English / 繁體中文)

  ・設定画面の言語は、右上の「言語」で切り替えられます。
    はじめて開いたときは、ブラウザの言語に合わせて表示されます。
  ・時計に出る言葉 (日付の曜日、午前/午後、「ことば」デザインの文など) は、
    ② の「時計の言葉」で選べます。標準は設定画面と同じ言語です。
  ・漢数字のデザイン (和風・短冊・金箔・筆文字) は、どの言語でも漢数字のままです。

■ 設定できる項目

  ・デザイン          100 種類から選択 (無料版は 8 種類)
  ・日付の場所        時計の上 / 下 / 左 / 右
  ・12 時間 / 24 時間   12 時間表示では AM/PM・午前/午後・出さない から選べます
  ・秒の表示          あり / なし
  ・コロンの点滅      あり / なし
  ・9 時台の書き方    09:05 / 9:05
  ・日付の表示と書式  10月3日(土) / 2026年10月3日(土) / 令和8年10月3日(土) /
                      2026/10/03 Sat / 2026.10.03 SAT / Sat, Oct 3
  ・言語              設定画面の言語 (日本語 / English / 繁體中文)。右上で切り替え
  ・時計の言葉        日付の曜日・午前/午後・「ことば」の文などの言語 (日本語 / English / 繁體中文)
  ・ひとこと          時計に添える短い文字 (例: JST、配信中)
  ・フォント          19 種類 (有料版)
  ・色                デザインごとのおすすめ配色、または最大 3 か所を自由に (有料版)
  ・大きさ            30% 〜 400%
  ・文字のフチ        太さと色 (有料版)
  ・影                あり / なし
  ・時刻の変わり方    ふわっと / スライド / ぽんっと (有料版)
  ・枠の中の位置      横 (左・中央・右) / 縦 (上・中央・下)
  ・タイムゾーン      「この PC の時刻 (標準)」でパソコンの時刻、
                      地域を選ぶとその地域の時刻を表示


■ うまく表示されないとき

  Q. 設定を変えたのに OBS の表示が変わらない
  A. ブラウザソースの「ローカルファイル」のチェックが入ったままだと、
     設定が反映されません。チェックを外して、URL 欄に
     settings.html で作った URL を貼り付けてください。

  Q. 文字が切れる / はみ出す
  A. ブラウザソースの幅・高さが小さすぎます。
     settings.html の ③ に表示される「幅 × 高さ」の数字を入れてください。
     秒・日付・ひとこと を足したり、大きさを上げたりした場合は
     おすすめサイズが変わりますので、URL を作り直したときに確認してください。

  Q. フォントが設定と違う
  A. フォントはインターネットから読み込みます。
     ネットにつながっていないと、パソコンにある代わりのフォントで表示されます。
     OBS を起動したままでも、ネット接続を確認して
     ブラウザソースの「現在のページのキャッシュを更新」を押してみてください。

  Q. 明るい画面の上で白い文字が読みにくい
  A. 「くわしい設定」の「文字のフチ」(有料版) を付けて、
     暗い色にすると読みやすくなります。
     無料版は、背景にプレートが付いた「ピル」「パステル」「7セグ」「ニュース」
     「和風」や、文字盤のある「アナログ」がおすすめです。

  Q. フォルダを移動したら表示されなくなった
  A. URL にはファイルの場所が含まれています。
     フォルダを移動・名前変更したときは、settings.html を開き直して
     URL を作り直し、OBS に貼り直してください。


■ ファイル構成

  clock.html      OBS のブラウザソースに登録する本体
  clock-data.js   デザインやフォントの定義 (削除・移動しないでください)
  settings.html   設定画面 (ここで好みに設定して URL を作ります)
  thumbs          設定画面の一覧用の画像です。消さないでください
  i18n            言語の辞書 (日本語 / 英語 / 繁体字)。消さないでください
  README.txt      この説明書 (日本語)
  README_en.txt / README_zh-TW.txt   英語版・繁体字版の説明書

  ※ これらのファイルとフォルダは、同じフォルダに置いたままにしてください。


■ 動作環境

  - OBS Studio 30 以降を推奨
  - Windows / macOS いずれも動作
  - 設定画面は Chrome / Edge などのブラウザで開いてください
  - フォントの読み込みにインターネット接続が必要です
    (つながっていなくても、代わりのフォントで時計は動きます)
